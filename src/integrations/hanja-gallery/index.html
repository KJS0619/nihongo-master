새 이미지 추가

엑셀 템플릿으로 여러 이미지 추가

CSV에는 이미지의 파일명을 적고, 실제 이미지 파일은 아래에서 따로 선택해 업로드합니다. 파일명으로 CSV 행과 이미지 파일을 연결합니다.

이미지 여러 개 등록하는 방법
  1. 엑셀 템플릿 다운로드를 눌러 CSV 템플릿을 저장한 뒤 Excel에서 엽니다.
  2. 이미지 한 장당 한 행씩 입력합니다. 열은 텍스트, 이미지파일명, 상세설명입니다.
  3. 이미지파일명에는 실제 이미지의 파일명을 확장자까지 정확히 적습니다. 예: 컴퓨터에 있는 파일이 hanja1.png라면 CSV에도 hanja1.png라고 입력합니다. 폴더 경로나 파일명 앞뒤 공백은 넣지 마세요.
  4. Excel에서 다른 이름으로 저장을 선택하고 파일 형식을 CSV UTF-8(쉼표로 분리)(*.csv)로 저장합니다.
  5. 아래 작성한 템플릿에서 저장한 CSV를 선택하고, 이미지 파일 여러 개에서 CSV에 적은 실제 이미지들을 선택합니다. 파일 선택 창에서 여러 파일을 한 번에 선택할 수 있습니다. 파일 선택 순서는 상관없고 파일명으로 자동 연결됩니다.
  6. 여러 이미지 추가를 누릅니다. 텍스트가 이미 등록되어 있거나 CSV에 대응 이미지가 없는 행은 건너뛰며, 결과 메시지에 추가/건너뜀 건수가 표시됩니다.

예: CSV의 이미지파일명 칸에 hanja1.png 입력 → 아래 이미지 선택 창에서 실제 hanja1.png 파일 선택. 파일 이름만 CSV에 적는 것으로는 업로드되지 않으며, 실제 파일도 반드시 선택해야 합니다.

텍스트와 상세설명, 이미지 파일은 Supabase에 저장됩니다. 저장하려면 관리자 로그인이 필요합니다. 이미 등록된 텍스트는 다시 등록할 수 없습니다.
